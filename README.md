This is a heavily (read: Claude did everything) ai coded repo, aiming to have some fun finding new type of decks in PTCGP.

It aims to find new decks by playing simulations of the game, with a small model behind it to continiously improve the deck and playstyle.

It now covers all cards currently (20-10-2026) in the game. There might be some small differences in logic, but the core logic should be the same.
